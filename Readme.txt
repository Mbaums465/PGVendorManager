The program is really a timer-manager. If you don't reset it and keep the data up to date, you are in trouble. 
I am allowing for entered times to be greater than 7 days so that you can track work orders. 

If you want to use my vendor data, find my vendors.db and place this into the character_data folder. 

As of Oct. 2025, I made it easier to run. Simply run VendorMe.bat with the .py folder in the same directory.
